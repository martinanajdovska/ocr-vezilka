# Phase 4 publication-grade dependencies.
#
# The neural model is a fine-tuned ``google/byt5-small`` (byte-level T5).
# Hugging Face ``transformers`` ships the model + ByT5 tokenizer; ``torch``
# provides the autograd / device backend (CUDA / Apple MPS / CPU);
# ``tokenizers`` is a transitive dep we pin explicitly so the byte-level
# tokenizer's behavior is stable across Python versions; ``accelerate`` is
# optional but lets ``transformers`` use ``device_map="auto"`` for users on
# multi-GPU setups.
#
# Install (Mac/MPS):
#     python -m pip install -r requirements.txt
#
# Install (Linux/CUDA 12):
#     pip install --index-url https://download.pytorch.org/whl/cu121 torch
#     pip install -r requirements.txt
#
# Install (CPU only):
#     python -m pip install -r requirements.txt
#     (no extra steps; CPU torch wheel is pulled by default)
